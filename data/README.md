# Data

Behavioral data and metadata introduced in White, Grimm, & Glass (2026)
*Aspect is not a fixed property of linguistic expressions* (ELM 2026).

Every trial-level file here is one row per (participant, item) observation,
with no aggregation. The trials dropped by the exclusion criteria have already
been removed (see paper §2, §3, §5). The similarity file retains the 8
calibration trials per participant (`verb_type == "calibration"`), though the
analyses in the paper filter them out. Raw JATOS dumps are not included in this
repository because they contain user identifiers.

## Where these files come from

Each trial-level CSV is built from the raw JATOS result files by a script in
[`scripts/`](scripts/README.md), which joins the responses to the sentence
inventory and the deployed stimulus lists. The raw dumps are not published
(they carry participants' Prolific IDs), but the scripts are included to
document how `data/` was produced and to help a researcher replicating this
data collection to quickly format their new data for analysis.

## Participant identifiers

Every value in a `participant` column is a UUID with no relationship to the
underlying Prolific ID. This matters because a Prolific ID is stable across
studies: publishing one would let anyone holding data from another study link
a participant between the two. The UUIDs carry no such linkage, and the map
that would undo them is kept out of the repository entirely.

The relabeling is one-to-one: each participant's trials remain grouped, and the
by-participant random effects are unaffected.

Because we assign a UUID per participant rather than per file, a participant who
took part in two studies keeps one UUID across both. Four IDs appear in two of
the three files: one in `data-cloze.csv` and `data-similarity.csv`, and three in
`data-proportion.csv` and `data-similarity.csv`. Five people in the raw JATOS
dumps took part in two studies, though. The fifth took part in Experiment 1a in
a condition with generic event descriptions (e.g. *People push things.*), which
the paper does not report and `data-cloze.csv` does not include, so only their
Experiment 2 data appear here. We counted these by matching Prolific IDs across
the raw dumps that the scripts in [`scripts/`](scripts/README.md) read, and
UUIDs across the three released files. (One further person, who appears only in
`data-proportion.csv`, also has an episodic Experiment 1a session in an interim
JATOS export that none of those dumps include; that session is not in
`data-cloze.csv`.)

## `manner-result-verbs.csv` (40 rows)

The 40 transitive English verbs that are used in the materials, organized in 20
manner-result pairs across seven semantic fields (cleaning, contact/contact-caused 
change, contact/contact-caused motion, violence, moving
liquid, moving substance, deliberation). Verb-type classifications are taken
from the lexical semantics literature cited in the paper.

| column      | description                                  |
|-------------|----------------------------------------------|
| `verb`      | bare verb form (e.g. `hit`)                 |
| `verb_past` | past-tense form used in stimulus sentences   |
| `verb_type` | `manner` or `result`                         |

See paper Table 1 in the paper for the field grouping and
provenance.

## `manner-result-sentences.csv` (166 rows)

Every event description used as a stimulus in any of the three experiments,
generated once and then deterministically slotted into the three task
materials. Each row is one PropBank (sub-)sense of one verb, and gives the
three versions of that description we report on (contentful, bleached, and
templatic), two generic versions used only in Experiment 1a, and the
Experiment 1a list each version was assigned to.

Each verb's PropBank senses (Palmer et al. 2005) were retrieved for the
transitive frame. Highly idiomatic senses and senses favoring determiners
other than *the* were not used. Each remaining sense was hand-labeled as
concrete or abstract, splitting a single PropBank sense into two rows when
both readings were available (e.g. `hit.01-concrete` for *The batter hit the
ball* and `hit.01-abstract` for *The idea hit the researcher*). Two contentful
sentences were then hand-written per (sub-)sense using definite NP arguments
in the past tense, and a bleached counterpart was generated by replacing the
contentful arguments with definite NPs headed by general nouns (`person`,
`thing`, plus `organization`, `event`, `time`, `place`, `stuff` where neither
of the primary two was natural). A templatic counterpart of the form `X
verb-PAST Y` was generated per verb following Kane et al. (2022).

Experiment 1a also ran two generic conditions, in which the contentful and
bleached descriptions were rewritten with bare plural or mass arguments in the
present tense (e.g. *Batters hit balls.*, *People hit things.*) and
participants chose a preposition and a time unit but no numeral. The paper does
not report these conditions, and `data-cloze.csv` does not include their
responses. The generic sentences are kept here because they are part of the
deployed Experiment 1a materials.

The `cloze_list_*` and `cloze_position_*` columns record where each sentence
appeared in Experiment 1a: which list it was assigned to and its position in
that list, both 0-based. `cloze_list_*` uses the same numbering as `list_num` in
`data-cloze.csv`. A sentence shared by several rows (for instance a bleached
sentence common to two senses of a verb) was one item, so every row carrying it
records the same list and position. `materials/scripts/make_items_json.py`
builds the deployed Experiment 1a lists from these columns.

| column                                            | description                                                                 |
|---------------------------------------------------|-----------------------------------------------------------------------------|
| `verb`, `verb_type`                               | as in `manner-result-verbs.csv`                                             |
| `propbank_sense`                                  | PropBank sense identifier (e.g. `hit.01`)                                  |
| `concreteness`                                    | `concrete` or `abstract`                                                    |
| `subject_noun_contentful`, `object_noun_contentful` | head nouns chosen for the contentful sentence                             |
| `subject_noun_bleached`,   `object_noun_bleached`   | head nouns chosen for the bleached counterpart                            |
| `*_plural`, `*_mass`                              | grammatical features of each chosen noun in the episodic sentences          |
| `sentence_contentful_episodic`                    | the contentful event description (used in Exp 1a/1b/2)                      |
| `sentence_bleached_episodic`                      | the bleached counterpart (Exp 1a/1b/2)                                      |
| `sentence_templatic_episodic`                     | the templatic version `X verb-PAST Y` (Exp 1a/1b only)                      |
| `sentence_contentful_generic`                     | generic counterpart of the contentful sentence (Exp 1a only; not reported)  |
| `sentence_bleached_generic`                       | generic counterpart of the bleached sentence (Exp 1a only; not reported)    |
| `cloze_list_<condition>`                          | Exp 1a list the `sentence_<condition>` item was assigned to (0-based), for each of the five conditions `contentful_episodic`, `bleached_episodic`, `contentful_generic`, `bleached_generic`, `templatic_episodic` |
| `cloze_position_<condition>`                      | position of that item within its list (0-based), the order in the deployed materials |

See the verb list in `manner-result-verbs.csv` plus PropBank.

## `data-cloze.csv` (Experiment 1a)

One row per cloze (blank-filling) response. The participant was shown an event
description containing three blanks (e.g. *The hurricane hit the coastline __
__ __.*) and filled them in via three dropdowns:

1. **preposition**: `in` or `for`.
2. **numeral**: one of `1, 2, 3, 4, 5, 10, 15, 20, ..., 95, 100`.
3. **duration**: one of eleven time-unit names, from `milliseconds` through
   `millenia` (the spelling used in the deployed materials).

All three columns record *participant choices*, not experimenter stimuli. In
this file, `preposition`, `numeral`, and `duration` are responses rather than
design features. The instructions asked participants to choose the values they
judged most natural.

| column                                      | description                                                              |
|---------------------------------------------|--------------------------------------------------------------------------|
| `participant`                               | pseudonymous participant UUID (see above)                                |
| `verb`, `verb_type`                         | the verb in the stimulus and its manner/result classification            |
| `propbank_sense`, `concreteness`            | identifies the (sub-)sense the contentful sentence instantiates          |
| `contentfulness`                            | `contentful`, `bleached`, or `templatic`                                 |
| `clause_type`                               | always `episodic` here (see above)                                       |
| `condition`                                 | concatenation of `contentfulness` and `clause_type`                      |
| `list_num`                                  | which Latin-square list the participant saw                              |
| `subject_noun`, `object_noun`               | head nouns in the actual sentence shown                                  |
| `*_plural`, `*_mass`                        | grammatical features of those nouns                                      |
| `sentence`                                  | the full event description (with the three blanks already filled in for display purposes) |
| `preposition`                               | participant's preposition choice: `in` or `for`                          |
| `numeral`                                   | participant's numeral choice                                             |
| `duration`                                  | participant's time-unit choice                                           |

**Counts**: 5,380 responses from 120 participants; 1,660 contentful + 2,120
bleached + 1,600 templatic. All episodic (see above).

Raw JATOS exports were merged across sessions, joined with
`manner-result-sentences.csv` to recover sentence-level metadata, and filtered
by the exclusion criteria. See paper §2.

## `data-proportion.csv` (Experiment 1b)

One row per proportion-judgment trial. Unlike Exp 1a, the stimulus here was a
fully realized sentence with the preposition, numeral, and duration unit
already filled in by the experimenter (for instance, *The hurricane hit the
coastline in 5 minutes*), and the participant chose one of five Likert
options answering *For what proportion of those 5 minutes (if any) was the
hurricane likely hitting the coastline?*. The five options were:

| `response` | label shown to participant                |
|------------|-------------------------------------------|
| `0`        | *None of those N units*                   |
| `1`        | *Less than half of those N units*         |
| `2`        | *About half of those N units*             |
| `3`        | *More than half of those N units*         |
| `4`        | *The entirety of those N units*           |

A response of `0` (*none*) signals non-overlap, while responses `1`–`4` signal
varying degrees of overlap. Because four of the five options indicate *some*
overlap, the analysis binarizes the response and §4 corrects for the resulting
baseline.

Same column structure as `data-cloze.csv` (with `preposition`, `numeral`,
and `duration` now denoting *stimulus* features rather than responses), plus:

| column     | description                                                          |
|------------|----------------------------------------------------------------------|
| `response` | the participant's choice, coded `0`–`4` as above                      |
| `rt`       | response time in milliseconds                                        |

As for `data-cloze.csv`, raw JATOS exports were merged, joined
to sentence metadata, and filtered by the exclusion criteria. See paper §3.

## `data-similarity.csv` (Experiment 2)

One row per pairwise similarity-rating trial. Each trial paired two event
descriptions sharing a verb (e.g. *The analyst cleaned the data* paired with
*The housekeeper cleaned the kitchen*); the temporal modifier was removed for
this task. Participants rated similarity on a continuous slider labeled
*completely identical* at the left edge and *extremely different* at the
right. The slider always began at the left edge (`slider_start = 0`) and
required movement before submission was allowed.

The file contains both test trials (verb-paired sentences, 10,800 rows
across `verb_type = "manner"` / `"result"`) and calibration trials (1,616
rows, `verb_type = "calibration"`). Each participant saw 8 calibration items
spanning four kinds (`very_similar`, `somewhat_similar`, `somewhat_different`,
`very_different`). Analyses in the paper drop these.

| column                                | description                                                                 |
|---------------------------------------|-----------------------------------------------------------------------------|
| `participant`                         | pseudonymous participant UUID (see above)                                   |
| `list_num`                            | Latin-square list                                                           |
| `verb`, `verb_type`                   | the shared verb; `verb_type` is `manner`, `result`, or `calibration`        |
| `contentfulness1`, `contentfulness2`  | `contentful` / `bleached` for `sentence1` and `sentence2` respectively (calibration rows: `contentful`) |
| `propbank_sense1`, `propbank_sense2`  | PropBank sense of `sentence1` and `sentence2`, as roleset plus gloss (e.g. `break.18: violate ...`); for a bleached member, the sense of the inventory row the pair was built from; `calibration` on calibration rows |
| `concreteness1`, `concreteness2`      | `concrete` / `abstract` for `sentence1` and `sentence2` (same provenance as `propbank_sense1/2`); `calibration` on calibration rows |
| `sentences_reversed`                  | despite its name, `True` when the pair was shown in (`sentence1`, `sentence2`) order on this trial and `False` when it was shown in (`sentence2`, `sentence1`) order |
| `sentence1`, `sentence2`              | the two event descriptions shown, in the pair's canonical order (the same for every participant), not necessarily the order of display |
| `response`                            | integer slider value in $[0, 100]$ (0 = *completely identical*, 100 = *extremely different*) |
| `rt`                                  | response time in milliseconds                                               |

Raw JATOS exports merged across sessions, joined with the
sentence inventory in `manner-result-sentences.csv` to recover per-sentence
metadata, exclusions removed per the exclusion criteria. See paper §5.

## `propbank-sense-distribution.csv` (5,291 rows)

Per-verb counts of PropBank rolesets, extracted from the English portion of
OntoNotes 5.0 (Weischedel et al. 2013). Feeds the multi-membership weighting
of bleached and templatic items in §2 and §3 and the same-sense predictor in §5.

| column                  | description                                       |
|-------------------------|---------------------------------------------------|
| `verb`                  | bare verb form                                    |
| `sense`                 | PropBank roleset (e.g. `hit.01`)                  |
| `count`                 | raw OntoNotes count of the roleset for the lemma  |
| `logp_sense`            | log of the marginal sense probability             |
| `logp_sense_given_verb` | log of $p(\text{sense} \mid \text{verb})$         |

Derived from OntoNotes 5.0, which is LDC-licensed and not redistributed
here. The extraction script is `data/scripts/make_propbank_sense_distribution.py`;
it rebuilds this file from a local copy of the OntoNotes release tarball
(with `ONTONOTES_ARCHIVE` pointed at it). See `data/scripts/README.md`.
