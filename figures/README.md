# Figures

This directory contains the four figures cited in White, Grimm, & Glass
(2026), each as a vector PDF and a raster PNG. They are written here by
[`analysis/reproduce.ipynb`](../analysis/reproduce.ipynb) and are tracked so a
reader can inspect them without running the analysis.

| File | Paper figure |
|---|---|
| `cloze_proportions_by_verb.{pdf,png}` | Figure 1 (§2) |
| `nonoverlap_by_verb.{pdf,png}` | Figure 2 (§3) |
| `aspect_plane.{pdf,png}` | Figure 3 (§4) |
| `similarity_by_match.{pdf,png}` | Figure 4 (§5) |
